# 🐍 Zmeya Arcade

Неоновый веб-сборник из 6 браузерных игр в ретро-аркадном стиле.
Чистый **HTML / CSS / JS** — без зависимостей, без сборки, без картинок.

[🎮 Играть онлайн →](https://meowler343.github.io/zmeya/)

## 🕹️ Игры

| Игра | Описание | Управление |
|---|---|---|
| 🐍 Змейка | Классика с порталами вместо стен и ускорением | Стрелки / WASD / свайпы / D-pad, пробел — пауза |
| 🧠 Память | Найди все пары рептилий за минимум ходов | Клик / тап |
| ⚡ Реакция | Жди зелёного — лови миллисекунды | Клик / тап |
| 🧱 Арканоид | 60 кирпичей, физика мяча, жизни | Мышь / стрелки / тач |
| 🎯 Кликер | 30 секунд: 🐍 = +3 очка, 😈 = −3 | Быстрые клики |
| ✂️ Камень·Ножницы·Бумага | Матч до 5 побед с историей раундов | Кнопки |

## ✨ Фишки

- 🌌 Живой фон: светящиеся пиксельные змейки + мерцающие звёзды
- 🔊 Ретро-звуки через WebAudio API (никаких аудиофайлов)
- 🏆 Рекорды в `localStorage` + общий счётчик очков
- 🎉 Конфетти при победах, глитч-логотип, адаптив под мобильные

## 🚀 Как запустить локально

Просто открой `index.html` в браузере — всё работает с `file://`.

Или через мини-сервер:

```bash
python3 -m http.server 8090
# затем открой http://localhost:8090
```

## 📤 Публикация на GitHub Pages

1. Создай репозиторий на GitHub (например, `zmeya`).
2. Запуши код:

   ```bash
   git remote add origin https://github.com/USERNAME/zmeya.git
   git push -u origin main
   ```

3. В настройках репозитория: **Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save**.
4. Через минуту сайт будет доступен по адресу `https://USERNAME.github.io/zmeya/`.

Обновления: `git add . && git commit -m "..." && git push`.
